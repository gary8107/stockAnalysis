### 二、核心論點：Intel vs 台積電技術與政治拆解（本集獨家亮點）

> ⭐ **本集主軸**：5/12 已提及「英特爾單純是政治讓利」，本集進一步把「**Intel 表面強勢的真實原因**」完整拆解，並對追逐 Intel 概念股的投資人提出**良率追蹤警示**。

#### 1. Intel 最近股價暴漲一倍的 5 個外溢因素

| 因素 | 內容 |
|---|---|
| **CPU 供不應求** | ASIC AI 伺服器、特殊用途伺服器爆滿；台積電 3 奈米/2 奈米接不完通用型 GPU/CPU 訂單 → Intel 接「**外溢訂單**」 |
| **政治壓迫** | 川普強迫蘋果、NVIDIA、特斯拉下單給 Intel；Intel **免費把股份送給美國政府** → 美國政府要分潤 |
| **分散風險** | 「去中化」浪潮下，大廠不想全押台積電（一旦地緣風險爆發無備用方案） |
| **美國製造政策** | 川普要求美國製造、不想晶片只依賴台灣生產（「**先進製程過去都集中在台灣，他並不想要**」） |
| **政策補助** | 川普政府直接補助 Intel，要求晶片回流美國本土 → Intel 就「規定你要下訂單給他」 |

→ **不是 Intel 超越了台積電，而是 Intel 接到了「台積電不接 / 接不完的」外溢訂單 + 政治籌碼**。
→ 老師金句：「**英特爾真的有比台積電強嗎？我的答案是不是；我的肯定句並沒有。**」

#### 2. Intel A18（18A）技術與台積電對照

| 項目 | Intel A18 / 18A | 台積電 |
|---|---|---|
| 製程奈米 | **介於 2 奈米 ~ 3 奈米** | 3 奈米、2 奈米已量產 |
| 良率 | ⚠️ **從未公布過** | **百分之百穩定**（已驗證多年） |
| 晶片供電方式 | **背面四角形**（EMIV） | 中間 |
| 封裝技術 | EMIV / 面板扇形封裝 | 目前 CoWoS，**2028 年會走 EMIV / 面板扇形封裝** |
| 功耗 | 兩家都很厲害 | 兩家都很厲害 |
| 接 AI GPU 能力 | 可以接（AI GPU 願意下單） | 可以接 |

→ Intel 18A **理論上對台積電有挑戰**（介於 2-3 奈米）；但**良率是死穴**。

#### 3. 良率風險 — 三星 7 奈米殷鑑（本集老師核心比喻）

- 老師援引「**三星 7 奈米搶台積電訂單 → 蘋果手機可以煎蛋**」的故事提醒投資人
- 客戶下單給 Intel 是為了「**對川普交代 + 分散風險**」；**良率不好 / 毛利不好 / 成本高是 Intel 自己要負責，不是客戶要負責**
- **投資建議**：可以追逐 Intel 概念股（聯電 100+ 等），但**要持續追蹤良率**；**若像三星一樣良率拉不上來、就是曇花一現**

#### 4. 聯電 2303 邏輯反詰（本集獨家）

- 聯電從 52 → 100+ 翻一倍（與陳昆仁 5/12 觀點一致）
- 老師反詰：「**如果 Intel 真的這麼厲害，他要你聯電做不到 3 奈米的東西嗎？**」
- **股票就是邏輯與統計學**：Intel 真的這麼強就不會找聯電做；找聯電是因為「Intel 自己接不完」

#### 5. 操作守則（延續 5/8 / 5/11 / 5/12 並再次強化）

- **不做死多頭、也不做死空頭** → 該怎麼樣就怎麼樣

- **支撐不破才買**：不是「有錢就買有錢就買」
- **短線者**：KD 灌破 80 出場
- **長線者**：拉回承接好股、長線保護短線
- **選股方向（沿用）**：

### 二、核心論點：高檔資金管理 + 散熱族群利空解讀

#### 1. 操作守則（延續 5/8，再次強化）

- **不要使用融資**：碰到三根跌停（如健策）會直接被請出場

#### 2. 選股方向（延續 5/8，再次列出）

#### 3. 對「散熱族群三根跌停」的關鍵解讀（本集重點）

- **起因**：市場傳言輝達 Vera Rubin / **Rubin Ultra** 規格改動 — 均熱片從**雙片改回單片**、不採用 MCL（微通道蓋板）
- **真實原因（老師解析）**：
  - **液態金屬鷹板**（鴻騰製作的金屬鍍金水冷板）有**漏液 / 外溢問題**，良率不穩
  - 雙均熱片 + 鍍金成本太貴（**均售價從 150 美元降到 50 美元**）
  - 輝達為了**統一規格 + 降低成本 + 拉高良率**，寧願先用「水冷板 + QD 快接頭 + 分歧管」的**水冷機櫃方案**
  - 不是不做 MCL，是**怕良率拖累交期**（GB300 / GB200 過去就出過這種問題）
- **後續可能性**：技術突破後，**Rubin Ultra 不排除再採用 MCL**，目前還沒確定
- **結論**：短期對健策、富士達、鴻騰確實是利空；但**還是會用到均熱片**，只是規格沒以前那麼高階

### 三、產業分析

#### 1. 估值典範轉移（延續 5/8）

#### 2. 矽光子 / CPO 主軸（2027~2028 最明確的方向）

- 不只台積電，**博通（Broadcom）、邁威爾（Marvell，逐字稿音譯 MyWare）** 也都要拼這塊

#### 3. CCL（銅箔基板）— 漲價範圍擴大（本集新增亮點）

- 過去通常只有 **M7 / M8** 高階漲價
- **本次自 4 月起，M4 以下（非高階材料）通通漲價**

#### 4. 記憶體：DDR4 vs DDR5

- **DDR4 沒漲**、**DDR5 漲翻了**
- 原因：**LPDDR5** 才是未來 AI 要用到的規格

#### 5. CPU 市場版圖變化

- 大客戶不想讓輝達 GPU 賺走全部利潤 → **CPU 拿回自己做**
- 因此出現 Intel 搶單、AMD 營收優於預期的現象
  - Intel：可能是台積電不做的單、或川普政治規定（Intel 有美國政府持股）
  - 客戶若自由選 → 還是會優先選台積電
  - 台積電產能不足才退而求其次選 Intel
  - AMD：GPU 不如輝達，但 CPU 不需要那麼先進製程（7 奈米就夠），自然受惠
